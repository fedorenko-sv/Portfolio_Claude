# Проверка реализации · графит и вишнёвый
27 октября 2026

## Реализовано
Обновлены главная, курсы, страница для бизнеса, каталог и четыре кейса. Введены отдельные файлы цветов, типографики и локальных шрифтов; документация дизайна и контента сохранена в репозитории. Общий каталог обновляет и Mini App. Русские названия заменили прежние бренды репозиториев в публичной подаче; плашки «Демо» убраны из портфолио.

Телефон — геометрическая сцена Three.js с отражениями, тенями и фактическим снимком меню. На странице курсов использован отдельно созданный предметный визуал. Навигация, практика, контакт, материалы и служебные страницы работают в общей системе.

## Автоматическая проверка
- npm run lint — успешно.
- npm run typecheck — успешно.
- npm test — 13/13.
- npm run build — успешно, 35 страниц в production build; черновики программ исключены.
- npm run test:e2e — 18/18.
- Проверены новые страницы на 320, 390, 768 и 1440 px; прежние страницы также на 360 px.
- Проверены явный запуск iframe, разворот, закрытие, размонтирование и возврат фокуса. В тесте оболочки удалённый документ подменяется синтетическим HTML; это не тест продуктовой логики.
- Сохранены существующие проверки практики, восстановления/удаления прогресса, работы без localStorage, 404 и API 503.
- Автоматическая проверка доступности ключевых страниц не нашла serious/critical нарушений. Это не полная сертификация доступности всех внешних приложений.

## Ручная браузерная проверка
Во встроенном браузере открыты главная, курсы и кейс размещения. Реальное удалённое приложение размещения загрузилось внутри iframe портфолио; проверен разворот. Записи, оплаты и внешние отправки не выполнялись. В журнале главной ошибок уровня error не обнаружено.

## Ограничения
Встроенная витрина доступна для предоставленного адреса размещения, который отличается от актуальной ветки. Остальные адреса требуют входа/доступа или ведут на публичный сайт центра; для них реализовано отдельное открытие с пояснением. Защита чужих приложений не отключалась. Живой HTML-экран внутри самого 3D-телефона не подключён, поскольку предоставленный ресторанный адрес не подтверждён как публично доступный.

Курсы по-прежнему draft; доступны в development/preview, скрыты в production. Новая форма обращений, серверная CRM, платежи и рассылки не добавлялись.

Скриншоты ревью находятся вне git: outputs/implementation-qa в рабочей папке. Визуальное сравнение и история исправлений — в корневом design-qa.md. Preview-публикация и фактический commit фиксируются в итоговом outputs/IMPLEMENTATION.md.
