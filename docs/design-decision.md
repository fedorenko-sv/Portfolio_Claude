# Визуальное решение

Актуальное решение следующей итерации: композиция варианта 2, графит/молочный и вишнёвый из варианта 3. Реализовано в коде по новой просьбе владельца. Канонический [дизайн-код](design/identity.md), [реализация](design/implementation.md), [проверка](implementation-qa.md). Описание ниже — история предыдущего этапа, не текущая палитра и типографика.

Показаны три desktop/mobile направления: авторская мастерская, журнал, продуктовая лаборатория (`docs/design-directions.html` — исходные эскизы). Владелец выбрал **первый**, но отклонил терракоту и шаблонный характер. Прямое уточнение: «нужен более человеческий, дорогой и дизайнерский стиль».

Текущая реализация переработана по этому ответу: сдержанная авторская редакционная композиция, без терракоты, разноцветных карточек и повторяющейся нумерации. Большой антиквенный заголовок, смещённая вправо курсивная вторая фраза, тихая типографическая иерархия и тонкие разделители. Продуктовые маршруты показаны как текстовые схемы, без имитации UI.

Токены: фон #F5F4EF, текст #252B29, вторичный #626862, акцент #334B45, вторичная поверхность #EAECE5, линия #CDD1C8. Без яркого акцента. Шрифты **Literata Variable** (заголовки и курсив) и **Manrope Variable** (текст/интерфейс), локальная поставка через Fontsource, SIL OFL; лицензии в `public/licenses`. Внешних font CDN нет.

Максимальная ширина 1240 px; на mobile одна колонка. Hero типографический, потому что настоящая фотография не предоставлена. Фото человека и продуктовые экраны не генерировались.

Desktop и mobile screenshots обновлённого первого экрана показаны владельцу. Новая композиция ещё не объявлялась окончательно утверждённой. Продолжается обычная разработка в preview; production не затрагивается.
