## Не проверено / не подключено

- Telegram Android/iOS/Desktop: нет сконфигурированного бота. Браузерные проверки не заменяют реальные клиенты. Авторизация через initData не реализована и не требуется для бесплатного контента; нет заявления о проверке подписи.
- Реальная доставка ответов бота: токен не предоставлен. Проверены command payload и durable dedup, не Telegram API.
- Серверная форма, БД, rate limit, same-origin/idempotency и success/400/429/storage failure: сбор выключен, endpoint всегда 503 без чтения тела. Для полного R1 нужны отдельная реализация и тесты по release checklist.
- Подтверждение прав на фото/клиентские media, полный продуктовый скрин/видео-пакет, независимая проверка статуса внедрений — отсутствуют.
- Копирование карточки зависит от Clipboard API; предусмотрена ручная копия при отказе. Системные настройки каждого устройства не проверены.
- Полевые LCP/CLS/INP и конверсия пока не измерялись. Лабораторные данные не выдавать за реальные показатели пользователей.

Node 22 выводит предупреждения experimental SQLite/strip-types и о модульном определении TS; это не ошибки тестов. Тестовые SQLite-файлы находятся в ignored `work/`, не являются хранилищем заявок сайта.
