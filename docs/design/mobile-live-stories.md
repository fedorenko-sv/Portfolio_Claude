# Живые страницы и управление касанием · 29.10.2026

Ветка: `codex/mobile-live-stories`. База: `codex/editorial-live-site`.

## Решения

- Рабочий стол: крупные нативные кнопки поверх предметов на touch-устройствах. Первое касание выбирает и подсвечивает предмет, повторное открывает раздел. Те же кнопки работают на постере без WebGL и в Save Data. Вертикальное движение остаётся прокруткой страницы. На ПК сохранён raycasting по геометрии.
- Для бизнеса: четыре учебных процесса, ручной выбор этапа или конечный проход с паузой. Смена сферы сбрасывает прогресс. Выход из области видимости и скрытие вкладки останавливают проигрывание. Кнопка ведёт в соответствующее настоящее приложение.
- Обучение: три авторских упражнения на проверку ответа. Исходные факты, выбор утверждения, объяснение и корректная формулировка. Работает локально, без AI API и отправки данных.
- Выступления: листаемый пример разбора из трёх слайдов. Реальные фотографии в горизонтальной галерее с touch scroll-snap, кнопками и полноэкранным просмотром. Escape закрывает просмотр и возвращает фокус; стрелки переключают фото.
- Обо мне: разворачиваемые заметки о критериях готовой работы вместо дополнительного списка обещаний.
- Тексты примеров в `src/content/experiences.ts`; единый визуальный язык и responsive-правила в `Experiences.module.css`. Используются существующие Manrope/Literata, графит, бумага, вишнёвый и розовый. Новых зависимостей нет.

## Референсы и адаптация

- https://bruno-simon.com/ — разные способы взаимодействия на мыши и телефоне. Взята идея явного touch-управления, исходники и визуалы не копировались.
- https://tympanus.net/codrops/2025/01/21/the-journey-of-creating-a-3d-portfolio/ — мобильная адаптация сохраняет интерактивность, одновременно упрощая управление.
- https://tympanus.net/codrops/hub/tag/draggable/ — перелистываемые фото и объёмная подача карточек. Здесь реализованы собственные CSS-стопки, нативная галерея и лёгкие переходы без дополнительного WebGL-контекста.

## Контент и происхождение

Все новые тексты — авторские иллюстративные сценарии. В них нет вымышленных клиентов, подтверждённых внедрений, цен на услуги или обещанных показателей. Цена в упражнении — намеренно неподтверждённая фраза учебного ответа, с объяснением ошибки после выбора. Слайды обозначены как пример разбора, а не запись прошлого выступления. Фото сцены и аудитории ранее предоставлены владельцем. Синтетические лица и мероприятия не создавались.

## Проверка перед публикацией

Касание текущего и другого предмета, повторный переход, вертикальный свайп, Save Data, уменьшенная анимация; выбор/пауза/переключение процесса; объяснение ошибки и сброс упражнения; фото, клавиатура, возврат фокуса; ширины 320/390/768/1440; axe, typecheck, lint, unit, production build и browser E2E. После публикации — те же ключевые действия на публичном домене без авторизации.

## Результат локальной проверки

- `npm run lint`, `npm run typecheck`, `npm test`: без ошибок, 20 модульных тестов.
- `npm run build`: production-сборка, 39 статических страниц, четыре пакета приложений на месте.
- `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3105 npx playwright test --reporter=line`: **68 passed (5.4m)** на окончательной production-сборке.
- Новые страницы: axe без нарушений на 320, 390, 768, 1440 px; фотопросмотр также проверен в открытом состоянии. Исправлены несовпадающая видимая подпись кнопки папки и неразличимые landmarks сайта/встроенного меню.
- Проверены реальные горизонтальные touch-жесты, вертикальная прокрутка на 3D-предметах, перетаскивание фото мышью, режим Save Data, уменьшенная анимация, клавиатура и возврат фокуса.
- 18 снимков окончательной сборки: `outputs/mobile-live-stories/` в корне рабочей папки Codex. Ошибок JavaScript при проходе по новым разделам нет.
- Браузерная проверка: Chromium и эмуляция touch-устройства. Физические телефоны и Safari в этой итерации не проверялись.
