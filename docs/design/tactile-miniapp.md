# Тактильный интерфейс и живая мастерская

Ветка: `codex/tactile-miniapp`. Сохраняем три направления, каталог, настоящие проекты и прямую связь с автором.

## Решение

- Mini App — личный рабочий блокнот: холодная светлая бумага, тёмный компактный док, вишнёвая обложка упражнения, читаемые листы библиотеки, фотография автора. Manrope для действий, Literata для выразительных заголовков. Без декоративной нумерации и повторяющихся крупных карточек.
- Палитра: бумага `#f4f5ee`, белый лист `#fffef9`, графит `#242525`, вишня `#8d2034`, розовый свет `#e9a5b2`. Тёмная тема использует ту же вишнёвую идентичность, без прежнего зелёного.
- Мастерская — главный выразительный момент: raycasting реальных объектов, подъём и подсветка при наведении, локальные частицы при выборе. Ноутбук, папка, микрофон выбирают то же направление, что доступные кнопки. Наведение не меняет выбранный текст. Касание работает без задержки и не мешает прокрутке.
- Остальные эффекты — ответ на действие: свет по поверхности видеообложек, движение стрелок, раскрытие листа, короткая смена страницы. Нет бесконечного движения, перехвата скролла и тяжёлых новых библиотек.

## Исправление обучения

В `ProgramCards` удалены номера, но глобальные стили сохраняли колонку 24–38 px. Название программы оказывалось в ней; `grid-column: 2` у описания создавал дополнительную колонку даже после мобильного переключения. Переносим сетку программы в CSS module, с явным компактным режимом для приложения. Проверяем 320, 390, 760 и 1440 px, включая режим с доступными черновиками и production без них.

## Ограничения и приёмка

- Реальная навигация, формы и просмотр проектов сохраняются. Никаких вымышленных результатов или опубликованных черновиков.
- Reduced motion: статическая подсветка и мгновенный выбор, без частиц/параллакса. Save-Data/WebGL failure: постер и доступные кнопки.
- WebGL только в видимой области, останавливается при уходе и скрытой вкладке; ресурсы освобождаются.
- Проверка: фактические hover/click по canvas, тач и клавиатура, контраст светлой/тёмной темы, отсутствие горизонтального скролла, переходы назад, упражнения и встроенные проекты.
- Production не изменяем; выдаём проверяемый preview.

## Выполнено и проверено

29 октября 2026:

- Новая главная Mini App, библиотека как рабочие листы, фирменный знак, плавающий док, единая вишнёвая тёмная тема, отдельная страница обучения с реальной фотографией и практикой.
- `ProgramCards` использует собственный CSS module; ширина заголовка до исправления на 390 px составляла 24 px. Регрессионная проверка воспроизвела ошибку; после исправления прошла на 320/390/760/1440 px с программами в режиме разработки. В production черновики остаются скрыты.
- Raycaster выбирает настоящую геометрию ноутбука, папки и микрофона. Hover подсвечивает предмет и показывает подпись, не меняя выбранное направление. Клик/касание выбирает направление; альтернативные кнопки работают с клавиатуры.
- Подъём предметов, открывание папки, движение экрана/микрофона, локальные световые пятна и 32 частицы на 850 ms. Без постоянного цикла частиц. Контекст, материалы, геометрия, текстуры и слушатели освобождаются.
- Короткая смена страницы через WAAPI без перехвата ссылок или сброса формы. Смена текста мастерской, свет на видеообложках, реакции стрелок, кнопок, закладок, открытие диалогов.
- `npm run build`, `npm run lint`, TypeScript — успешно. `npm test`: 20/20. Полный Playwright на production-сборке: 49/49 (3 минуты).
- Проверены responsive, Axe (включая тёмную тему), reduced motion, Save-Data, управление касанием, hover/click по геометрии, полноценные действия в четырёх встроенных приложениях и восстановление фокуса.
- Реальные скриншоты production-сборки сохранены в `outputs/tactile-miniapp/` рабочей папки Codex.

Бот отложен владельцем. Реальный Telegram-клиент пока не проверялся; браузерный вариант и адаптер Telegram с тестовым SDK проверены. Новых npm-зависимостей нет.

Технические источники: [Three.js Raycaster](https://threejs.org/docs/#api/en/core/Raycaster); локальная документация установленного Next 16.4.3. React ViewTransition не включался: текущий React 19.2.3 сохранён, используется обычная браузерная анимация.
