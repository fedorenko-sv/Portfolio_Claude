# Реализация авторского сайта

Ветка codex/author-site-growth. Основа — 751ab17 ветки codex/ecosystem-r1.

Основные секции используют src/components/site/Growth.module.css; контакт — src/styles/contact.css. Новые секции не переопределяют старые home-* классы. Старые файлы сохранены для незатронутых страниц, каталога, Mini App и просмотрщика.

Авторский контент: src/content/author.ts. Направления: offers.ts. Видео: media.ts. Темы и тексты обращения: src/lib/contact-draft.ts. Шаблон не уходит на сервер; Telegram получает текст только по явному переходу пользователя.

ProjectFilm использует native dialog, video создаётся только при открытии. Escape/close возвращают фокус, закрытие удаляет video. При скрытой вкладке воспроизведение приостанавливается. Событие pause-films останавливает предыдущее воспроизведение. Нет автозвука. VTT объясняет шаги без озвучки. Ошибка загрузки показывает ссылку на проект и повтор.

Папка — предоставленный растровый предмет с движением в CSS и раскрывающимся примером рабочего листа. Это 2.5D-подача, а не новая GLB-модель. Полноценная 3D-папка и общий showreel — необязательные задачи следующего этапа.

Телефон загружается при приближении к viewport. RAF останавливается вне экрана и в скрытой вкладке, при reduced-motion / Save-Data. Существующее живое меню и протокол same-origin сохранены.

Проверять: npm run lint, npm run typecheck, npm test, npm run build, npm run test:e2e. Для разработки новой ветки порт 3101, чтобы не затрагивать старый preview. Полный build требует owner-only пакеты public/showcase/rehab и lessons; они не коммитятся.
