# Визуальная корректировка · 27 октября 2026

Последние замечания пользователя имеют приоритет над первоначальным макетом.

- Вишнёвая папка на тёмном графите #1c1d1d. Основная палитра остаётся в colors.css, типографика — typography.css.
- Декоративных номеров 01/02 нет. Нумерация инструкций сохраняется там, где означает последовательность действий.
- Проекты показывают реальные интерфейсы сразу на странице. Статические WebP обложки открывают существующие локальные приложения по нажатию; это не постоянно работающие iframe.
- Обложки сняты с подготовленных клиентских приложений с учебными данными. При обновлении приложений обновлять и public/images/projects.
- Телефон свободен над низким постаментом. Плавный поворот вслед за указателем, спокойное движение в покое; анимация останавливается вне экрана и при reduced-motion. При работе с меню телефон неподвижен.
- Появление секций при прокрутке использует CSS view timelines; неподдерживающие браузеры показывают содержимое без анимации.
- Основные корректировки композиции: src/styles/visual-refinement.css. ProjectViewer объединяет запуск по обложке и по текстовой кнопке.
- Фото пока не добавлять. В дальнейшем: портрет рядом с рассказом о Сергее, репортажные фотографии на страницах курсов и выступлений.
