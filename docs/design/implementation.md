Дизайн-код: src/styles/colors.css, typography.css, fonts.css; композиция: site.css и audit.css. Растровые эталоны приоритетнее старых текстовых описаний. Новые русские названия и четыре проекта объясняют дополнительный ряд главной. Служебные ссылки и copyright сохранены в подвале.

## Встроенные приложения

Все адреса фиксированы в src/content/project-showcases.ts и находятся на одном origin в /showcase/. Оболочка лениво создаёт iframe, ожидает подтверждение готовности от нужного окна и origin, отменяет таймер, поддерживает разворот, Escape и возврат фокуса. Геометрический Three.js-телефон содержит живой CSS3D HTML-экран. На мобильном управление разворачивается в плоский экран с постоянной кнопкой закрытия. Статичный экран до активации — снимок настоящего меню.

|---|---|---|

CSP запрещает этим клиентам соединения с внешними API и разрешает встраивание только своим origin. Никаких рабочих авторизаций или изменения общих данных. SSO и заголовки исходных проектов не менялись.

## Закрытые исходники и сборка

Репозитории размещения и уроков PRIVATE. Их клиентские артефакты исключены из публичного Git через .gitignore. Для полного preview они передаются непосредственно в сборку Vercel в аккаунте владельца. Публичный Git содержит интеграцию и артефакты только публичных CRM и меню. Build намеренно требует все четыре пакета: неполный checkout без приватного пакета не должен давать ложный успешный preview.

Локальный комплект воспроизведения с патчами и presentation-файлами сохранён владельцу отдельно в outputs/audit-implementation/source-kit.zip. Он не публикуется в Git. Перед будущим релизом восстановить закрытые артефакты и проверить scripts/verify-showcases.mjs. При изменениях upstream пересобрать из закреплённых веток и повторить браузерные сценарии; пакеты не обновляются незаметно.

Production сайта и других проектов не менялся. Программы draft по-прежнему скрыты в production. Бот, платежи и приём заявок не расширялись.
