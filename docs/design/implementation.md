# Реализация дизайна
27.10.2026

Актуальная просьба пользователя «реализуй в коде теперь проект по плану» заменяет прежнюю границу «только файлы». Работа выполнена в ветке codex/ecosystem-r1 личного сайта. Продуктовые репозитории и production-настройки не менялись.

## Где закреплены правила
- src/styles/colors.css — канонические цвета и роли поверхностей.
- src/styles/typography.css — семейства и размерная шкала.
- src/styles/fonts.css — локальные подключения шрифтов.
- src/styles/site.css — композиция, компоненты и адаптивные состояния.
- docs/design — дизайн-код и переносимые токены.
- docs/content — редакционные тексты.
- src/content/catalog.ts — общий типизированный каталог сайта/Mini App.
- src/content/project-showcases.ts — проверенные адреса и разрешённые режимы просмотра.

## Просмотр приложений
Система размещения загружается живым iframe по действию пользователя. Текущий опубликованный адрес отличается от описанной актуальной ветки; это поясняется рядом с просмотром.

CRM открывает публичный сайт центра; кабинет сотрудника не открыт для произвольного посетителя. Платформа уроков требует входа и запрещает стороннее встраивание. Ресторанный адрес защищён Vercel для анонимных запросов. Для этих трёх источников реализованы понятное пояснение и внешнее открытие. Не отключались защита и авторизация.

3D-телефон — настоящая геометрия с реальным снимком меню на экране. В этой итерации он не содержит живую HTML-поверхность: целевой публичный адрес для неё пока не доступен без ограничений. Замена источника на открытую разрешённую витрину — следующий шаг, после которого оболочка может использовать режим embedded.
