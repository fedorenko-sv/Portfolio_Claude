# Цвета
Канонические значения для всей системы. Новые оттенки — только с понятной ролью.

| Токен | HEX | Назначение |
|---|---|---|
| graphite | #242525 | Основной тёмный фон; основной текст на светлом |
| chalk | #F4F5EE | Светлый фон; текст на графите и вишнёвом |
| cherry | #8D2034 | Главный акцент; CTA; большие цветовые поля |
| cherryHover | #A72D44 | Наведение на вишнёвую кнопку |
| cherryPressed | #71182A | Нажатие |
| rose | #E9A5B2 | Фокус и акцентные ссылки на тёмном |
| mutedDark | #B8BBB5 | Второстепенный текст на графите |
| mutedLight | #62675F | Второстепенный текст на молочном |
| lineDark | #626861 | Декоративные разделители на графите |
| lineLight | #858A80 | Разделители и границы на молочном |

## Сочетания
Расчёт контраста sRGB по формуле относительной яркости, округление до 2 знаков. Это проверка пар токенов, не аудит готового сайта.

| Передний / задний | Контраст | Правило |
|---|---|---|
| chalk / graphite | 14,01:1 | Основной текст |
| chalk / cherry | 8,01:1 | Текст и иконки на акценте |
| cherry / chalk | 8,01:1 | Ссылки и кнопки на светлом |
| rose / graphite | 7,68:1 | Фокус и ссылки на тёмном |
| mutedDark / graphite | 7,91:1 | Пояснения на тёмном |
| mutedLight / chalk | 5,28:1 | Пояснения на светлом |
| chalk / cherryHover | 6,17:1 | Текст кнопки при наведении |
| cherry / graphite | 1,75:1 | Только декоративные крупные детали |
| lineDark / graphite | 2,69:1 | Только разделители, не единственная граница поля |
| lineLight / chalk | 3,22:1 | Границы элементов на светлом |

## Роли по поверхностям
Тёмная: текст chalk, второстепенный mutedDark, ссылка chalk или rose с подчёркиванием. У вишнёвой кнопки светлая граница, чтобы контур отличался от фона. Фокус rose, внешний отступ 3 px.

Светлая: текст graphite, второстепенный mutedLight, ссылка cherry. Фокус cherry, внешний отступ 3 px.

Вишнёвая: текст chalk, второстепенный текст тоже chalk без снижения opacity. Главная кнопка chalk с текстом cherry. Фокус chalk.

Граница интерактивного поля на графите — mutedDark; lineDark оставлен декоративным. Состояние ошибки определяется текстом и значком, а не одним цветом. На графите использовать rose; на светлом — cherry. Для успеха достаточно нейтральной галочки и ясного текста; новый зелёный не вводить.

## Использование акцента
На первом экране достаточно подставки телефона и одной основной кнопки. В тексте не выделять вишнёвым каждое ключевое слово. Вишнёвая полоса может занимать целую секцию, если в ней один призыв. Фотографии и интерфейсы сохраняют собственные цвета.
