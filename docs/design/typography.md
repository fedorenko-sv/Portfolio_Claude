# Типографика

## Семейства
**Manrope** — навигация, заголовки, основной текст, кнопки, интерфейсные подписи. Начертания 400, 500, 600, 700, 800. Кириллица обязательна. В текущем проекте шрифт уже предусмотрен локально; этот пакет не меняет подключение.

**Literata** — короткая редакционная фраза, подпись на предметном объекте, редкий акцент в длинном чтении. Начертания 400/500, курсив только для осмысленного акцента. Не смешивать два семейства внутри каждого заголовка. На одной странице обычно достаточно одного применения Literata.

Резерв: Manrope → Arial → sans-serif; Literata → Georgia → serif.

## Шкала
Размеры в px; line-height — множитель; tracking — em. При реализации масштабировать через rem и проверить увеличение текста.

На ширине 320–359 px: hero 40, заголовок страницы 38, заголовок секции 32, название проекта 26. Разрешить естественный перенос вместо уменьшения основного текста.

## Русские названия
Карточки/строки не сокращают названия до английского бренда. Для сложных строк отводить 5–6 колонок desktop. Не обрезать многоточием; ограничение по строкам не должно скрывать смысл.

Рекомендуемые смысловые переносы:
- CRM для / образовательных центров
- Система размещения / и сопровождения гостей
- Платформа интерактивных / уроков и лекций
- Интерактивное меню / для ресторана

Переносы — ориентир для композиции, не жёсткий br на всех ширинах. Предлоги по возможности остаются со следующим словом. Сокращённые подписи разрешены в переключателе просмотра: «Образование», «Размещение», «Уроки и лекции», «Ресторан».

## Редакционные правила
Ё сохраняется; русские кавычки «»; названия продуктов в заголовках без кавычек. CRM и ИИ допустимы как понятные сокращения; Mini App впервые пояснять как мини-приложение. Без ALL CAPS в основных заголовках. Рубрика в капсе — максимум несколько слов.

Не растягивать длинную строку по ширине и не выравнивать основной текст по обоим краям. Ширина абзаца 52–62 знака, разделение абзацев 16–24 px. Списки в кейсах короткие и конкретные.

Проверить кириллицу, цифры, №, ₽, тире и стрелку на фактически подключённых файлах шрифтов. Не обещать совпадение растрового макета с метриками шрифта без вёрстки.
