# Portfolio / Ecosystem R1

Next App Router, TypeScript, React, Tailwind. Сайт и Mini App используют src/content/catalog.ts. Практика без AI API; локальный прогресс 30 дней.

Команды: npm ci; npm run dev; npm run lint; npm run typecheck; npm test; npm run build; npm run test:e2e. Сначала проверить scripts package.json.

Работать в отдельной ветке, сохранять пользовательские изменения. Не менять другие продуктовые репозитории. Production только с отдельным разрешением владельца. Не менять модель/аккаунт. Не делегировать без запроса пользователя.

Статусы/ограничения кейсов видимы. Draft программ не публиковать в production. Не выдумывать внедрения, метрики, отзывы, даты, цены и партнёрства. Private code не публиковать. Только синтетические данные в изолированном demo; медиа с разрешением и asset manifest.

R1-static: прямой контакт, серверный сбор заявок выключен. Не добавлять форму с fake success. Для полного R1 сначала согласовать PostgreSQL/регион, оператора и хранение. Не логировать контакты, сообщения, initData и токены. Не добавлять платежи/рассылки/AI-чат.
